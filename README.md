# Toy OpenGL Renderer

This is a mini renderer I am making to learn more about the graphics pipeline and deferred rendering specifically.
Summary of work progress and new concepts learnt can be found [here](WorkProgress.md).

## Project Overview
The scope of this project is to implement a simple but well-rounded renderer that runs in real-time at a reasonable fps.
